# RapidRescue Emergency Coordination Frontend

A React + Vite emergency-response prototype redesigned around a modern blue/lavender healthcare SaaS visual system.

## Included demo roles
- Citizen: emergency reporting, location, priority, tracking, Helper Mode
- Dispatcher: operations dashboard and response analytics
- Driver: assigned emergency workflow

## Run locally
```bash
npm install
npm run dev
```

The application uses mock/demo data and browser localStorage. No backend is required.
